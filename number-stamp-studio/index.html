Number style

Style changes apply to the selected stamp, or to future stamps when none is selected.

Selected number

Changing a number moves it to that position in the sequence. Later labels shift automatically. Drag labels using the Select tool.

Sequence

Set Next number to insert a stamp at that position and shift existing stamps up.
