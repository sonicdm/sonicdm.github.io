# sonicdm

Interactive web projects — games, simulations, and small tools hosted on GitHub Pages.

## Projects

### [Story Swapper](story-swapper-pro/)

Mad Libs-style word swap fun — fill-in-the-blank stories, public-domain books and poems, or create your own templates.

### [FH6 Randomizer](fh6randomizer/)

Pick a random car category, performance class, and event from the Forza Horizon 6 datasets. Filter the pools, lock anything you like, then reroll the rest.

### [Terrain Erosion](webgl-erosion-enhanced/)

Real-time WebGL terrain generation with hydraulic erosion simulation. Explore procedurally sculpted landscapes in the browser.
